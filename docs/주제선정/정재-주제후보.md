# 이정재

## **LLM 기반 피싱 이메일 탐지 웹 서비스**

- 요구사항: 사용자는 이메일 본문(또는 .eml 파일)을 업로드/붙여넣기 가능, AI가 피싱 여부를 판단하고 의심 근거(긴급성 유도 문구, 위조 링크, 발신자 스푸핑 등)를 항목별로 하이라이트하여 위험도 점수와 함께 제공한다.
- 프론트는 React로 입력 폼과 탐지 결과 시각화 UI 구성 / 백엔드는 FastAPI로 LLM API 호출 및 룰베이스 검증(URL 분석, 도메인 유사도 체크)을 결합한 하이브리드 탐지 파이프라인 구축한다.
- 추가내용: LLM의 자연어 판단 능력과 규칙 기반 보안 로직을 바이브코딩으로 어떻게 통합할 수 있을지 분석 / 오탐(FP)·미탐(FN)을 줄이기 위한 프롬프트 설계와 테스트 케이스 작성 과정에서 AI가 보안 도메인 지식을 얼마나 신뢰성 있게 다룰 수 있는지 분석
